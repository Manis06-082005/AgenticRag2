Agentic RAG Project Guide
What is RAG?
Retrieval-Augmented Generation (RAG) combines document retrieval with language
generation. It retrieves relevant source material to help answer a question.
Data Ingestion
The ingestion component loads PDF, TXT, Markdown, CSV, and DOCX files.
Each loaded document contains text and metadata identifying its source.
Plain text files in this project should use UTF-8 encoding.
Document Processing
After ingestion, documents are divided into smaller chunks. These chunks are
converted into embeddings and stored in a vector database for retrieval.
Example Project Policy

Source documents are stored in the data directory.

state that the available documents do not contain the answer.
